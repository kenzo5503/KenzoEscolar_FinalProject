# The College Survival Kit (TCSK)

A free, student-made resource website for students at FEU Alabang. It brings together must-know study websites, places around campus, budget meals and cheap food spots in one page.

**Live site:** https://kenzo5503.github.io/KenzoEscolar_FinalProject/
**Repository:** https://github.com/kenzo5503/KenzoEscolar_FinalProject

## Built with
- HTML5 and CSS3 (no JavaScript)
- Google Fonts: Poppins and Inter

## Features
- Responsive layout for mobile, tablet and desktop
- Menu links change color on hover
- Mobile menu and FAQ built with CSS and HTML only
- Fixed photo sizes so all cards line up
- Download Budget Template button (budget-template.csv)
